- It will be like I do npx @parthmunjal07/better-work all the md files for the agetn are added

- These files instructions given below
   1. Description for the agents to do atomic commits i.e.
      - Every commit encapsulates one logical unit of change.
      - Leaves the codebase in a working state (i.e., all tests pass).
      - Doesn’t mix concerns (e.g., formatting and logic changes together).
   2. Spec Driven Development for the project
      - Every Spec answers 4 ques
         a. What are we building?
         b. How should it behave?
         c. What must never happen?
         d. How will we verify it?
   3. An empty Plan.md with below fields to fill up for the user
      - The Problem
      - Tech Stack
      - User Story
      - Features
